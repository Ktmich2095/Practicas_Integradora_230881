# Práctica 03 - Boceto de Modelo Canvas con Archify

## Descripción

En esta práctica se generó un **Business Model Canvas** utilizando **Codex** y la herramienta **Archify**.

La aplicación multiplataforma seleccionada fue **Mercado Libre**, debido a que integra comercio electrónico, pagos, logística, publicidad y servicios digitales mediante aplicación móvil y plataforma web.

Se realizó un primer prompt para generar el modelo y posteriormente se mejoró para obtener un resultado más completo y detallado.

## Herramientas utilizadas

- Codex CLI
- Archify
- Git y GitHub
- HTML
- Visual Studio Code

## Proceso

1. Selección de Mercado Libre como aplicación multiplataforma.
2. Creación del prompt inicial.
