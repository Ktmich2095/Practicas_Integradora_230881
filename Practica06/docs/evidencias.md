# Guía de evidencias

1. Abrir `sketches/index.html` en un navegador. No requiere servidor ni dependencias.
2. Usar “Ver todo el tablero” y capturar las tres secciones. El tablero tiene desplazamiento horizontal para conservar las proporciones del teléfono.
3. Capturar las filas necesarias para que las 27 pantallas y sus flechas se lean. Puede reducirse el zoom del navegador para mostrar más tarjetas.
4. Capturar el mapa de conexiones compartidas y la bifurcación Inicio → Comprador / Vendedor.
5. Recorrer los botones del flujo Comprador y Vendedor; capturar al menos detalle del producto, confirmación de compra, crear publicación y preparar envío.
6. Abrir `diagramas/flujo_pantallas.md` en un visor compatible con Mermaid y capturar el diagrama.
7. Opcional: usar “Imprimir / Guardar PDF” para exportar todas las pantallas. Las flechas se revisan en el tablero y en Mermaid; la impresión prioriza la legibilidad de las tarjetas.
8. Agregar las capturas en una carpeta `docs/capturas/` creada por ti y sustituir los espacios del README con enlaces Markdown a cada imagen.

## Publicación estática

Los sketches usan rutas relativas y pueden servirse con GitHub Pages. Tras publicar el repositorio, la ruta será `<URL publicada>/sketches/` si Practica06 es la raíz, o `<URL publicada>/Practica06/sketches/` si forma parte de un repositorio de prácticas. Pegar la URL real en el README. Esta entrega no publica el repositorio ni inventa un enlace.

## Alcance de la demostración

Los enlaces entre pantallas son interactivos. Los campos, filtros, imágenes, pagos, carga de fotos y estados de envío son placeholders académicos. La vista individual se recupera al pulsar “Ver todo el tablero”. El escenario de calificación representa el pedido una vez entregado.
